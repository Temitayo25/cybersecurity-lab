# Cybersecurity Lab

My practical cybersecurity learning journey, covering security concepts, Linux, cryptography, identity and access management, and controlled hands-on labs.

## Topics
- Linux command-line fundamentals
- Offensive and defensive security
- Cybersecurity roles
- CIA triad, DAD, defence-in-depth, and Zero Trust
- Identity and Access Management
- GPG and OpenSSL encryption
- RSA asymmetric cryptography
- SHA-256 and HMAC
- John the Ripper password auditing
- PKI and certificate signing requests

## Safety
All activities are performed in authorized or isolated lab environments. Never upload private keys, passwords, real credentials, or sensitive data.

## Structure
- `notes/` — learning notes and command references
- `cryptography/` — practical cryptography labs
- `progress/` — learning progress tracker

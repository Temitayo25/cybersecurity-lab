# Cybersecurity Fundamentals

## Offensive Security
Asks: **How could an attacker get in?**

Includes authorized penetration testing, vulnerability assessment, and red-team exercises.

## Defensive Security
Asks: **How can we prevent, detect, and respond to attacks?**

Includes patching, monitoring, security awareness, incident response, and threat intelligence.

## Important Roles
- Security Analyst: investigates and assesses risks and events.
- Security Engineer: designs, implements, and maintains security controls.
- Incident Responder: handles security incidents.
- Digital Forensics Examiner: examines digital evidence.
- Malware Analyst: studies malicious software.
- Penetration Tester: performs authorized security tests.
- Red Teamer: simulates adversary behavior within an agreed scope.

## Common Threats
- DoS/DDoS: overwhelms a service.
- Malware: malicious software.
- Man-in-the-Middle: intercepts communication.
- SQL Injection: manipulates unsafe database queries.
- Phishing: tricks users into unsafe actions.
- XSS: injects scripts into web pages.
- Zero-day: exploits a vulnerability before a fix is available.
- Social engineering: manipulates people psychologically.
- APT: long-term targeted activity by organized attackers.

## Defensive Cycle
`PREVENT → DETECT → RESPOND → RECOVER → IMPROVE`

## Terms
- SOC: Security Operations Center
- DFIR: Digital Forensics and Incident Response
- SIEM: Security Information and Event Management

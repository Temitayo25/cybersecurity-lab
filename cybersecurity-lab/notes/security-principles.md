# Security Principles

## CIA Triad
- **Confidentiality:** only authorized people can access information.
- **Integrity:** information is not improperly changed.
- **Availability:** systems and information are accessible when needed.

## DAD
- Disclosure
- Alteration
- Destruction/Denial

## Models
- **Bell-LaPadula:** confidentiality; no read up, no write down.
- **Biba:** integrity; no read down, no write up.
- **Clark-Wilson:** integrity through controlled procedures and verification.

## Defence-in-Depth
Uses multiple layers of security instead of relying on one control.

## Zero Trust
**Never trust, always verify.**

## Design Principles
- Least privilege
- Attack surface minimization
- Centralized parameter validation
- Centralized security services
- Safe error and exception handling
- Secure by design

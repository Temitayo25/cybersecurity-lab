# Identity and Access Management

## IAAA
1. **Identification:** claiming an identity.
2. **Authentication:** proving the claimed identity.
3. **Authorisation:** deciding what the user may access or do.
4. **Accountability:** recording actions so activity can be traced.

## Authentication Factors
- Something you know: password or PIN
- Something you have: phone or security key
- Something you are: fingerprint or face
- Somewhere you are: location
- Something you do: behavior

## Authorisation vs Access Control
- Authorisation is the decision or policy.
- Access control is the mechanism that enforces the decision.

## Logging and SIEM
Logs record events such as logins, file access, permission changes, and errors. Logs may be forwarded to a central SIEM for analysis and alerting.

## User Lifecycle
`Onboarding → Access assignment → Role changes → Offboarding → Access revocation`
